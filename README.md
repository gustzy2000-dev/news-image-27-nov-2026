# The World in One Day — 27 November 2026

A newspaper front page summing up the world's news of Friday, 27 November 2026, in a single image. The page is composed in HTML and CSS with real, legible headlines — the drone attack in Kuwait that killed two Italians, Trump pressing Putin over Ukraine, tankers hit by mines in the Strait of Hormuz, Thanksgiving storms cutting power to about a million Americans, and more — and rendered to `entry.png` (1024×1024).

`main.ts` verifies the image is a genuine 1024×1024 PNG and copies it to the output directory. No network access is needed at run time.
